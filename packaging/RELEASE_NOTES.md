**Pilot test build for Windows. Nothing to install.**

1. Under **Assets** below, click **Marcelorian-…-windows.zip** to download it.
2. Follow the guide: [How to use Marcelorian](https://github.com/SoRRad/Marcelorian/blob/main/docs/TESTER_GUIDE.md). The same guide is inside the zip.

The `.sha256` file lets the program owner check the download is unchanged.

Marcelorian never sends email by itself: you press Send in Outlook, one email at a time.
